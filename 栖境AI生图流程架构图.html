点选与文字矛盾时弹"请确认"，二选一：以点选位置为准 / 以文字描述为准
U4

引用这张图（继续修改）/ 下载 / 重新生成；成功后版本号 V1、V2、V3 递增，历史结果均可引用与下载

F1

F2
任务快照
冻结素材、坐标、操作类型与 Prompt 版本，后续轮次与重新生成均沿用快照

五阶段：理解需求 → 生成基础效果 → 优化空间与光影 → 检查结果 → 完成；排队时提示"正在百炼后台处理…"
▼
服务端编排层 Cloudflare Worker
B1
统一入口 /api/generate-stage
前端唯一接口，浏览器请求不带 Key；返回仅含结果数据与 request_id
B2
四轮调度与轮询
R0→R1→R2→R3 串行执行，任一轮失败即任务失败；生图异步提交后轮询取图，单轮实测约 41–45 秒
无服务端数据库 · 无后台队列
API Key 仅存服务端环境变量
提示词组装（随任务快照冻结，版本 V1 / V2 / V3 递增）
① 任务说明
操作类型（添加 / 替换）+ 目标位置与落点坐标
② 商品描述
参考商品图：品类、颜色、材质与造型特征
③ 空间描述
R0 分析 JSON：房间结构、光照方向、装修风格
④ 要求与约束
尺寸、风格统一、光影一致、透视自然
→ 最终提示词送入 R1 / R2 生图与修正

AI 能力层 · 阿里云百炼
R0需求解析
qwen3-vl-plus
输入：基础图 + 要求
输出：JSON（空间理解 · 落点评估 · 尺寸比例）
不生图
R1基础生成
qwen-image-3.0
输入：任务快照 + 分析 JSON + 商品参考图
输出：图 1
R2综合修正
qwen-image-3.0
输入：修正要求 + 图 1（主编辑） + 基础图（锁背景）
输出：图 2
R3质量检查
qwen3-vl-plus
输入：图 2 + 检查标准
输出：评分（PASS / WARN / 服务不可用）
R3
质量检查
PASS → 交付最终图（标注 QC PASS）
服务不可用 → 交付图 2，标注 QC 待确认
FAIL → 唯一一次纠错生图（图 3）→ 复检，仍失败则展示纠错图并标 QC WARN
QC 检查项（R3 评分标准）
  • 商品外观与参考图一致
  • 光影方向与原空间匹配
  • 比例、透视与落点合理
  • 边缘融合自然，无拼贴感
生成失败：失败卡显示错误信息，下方红色"重新生成"按钮
常见错误类型：
· 网络中断（Failed to fetch）→ 重新生成或稍后再试
· 百炼 400 / 500（如账户欠费）→ 需运营检查百炼账户
· 轮询超时（150 次上限）→ 重新生成
↺ 用户手动重新生成 = 新任务沿用素材，从 R0 重来（非自动循环）

数据与治理层
D1
localStorage
历史对话 / 任务记录 / Prompt 模板；上限约 12 段对话，换设备或清缓存会丢失
D2
结果图
云端图片 URL，浏览器直接展示；下载文件名"栖境AI-效果图.png"
D3
排障与审计
每轮 request_id，管理员可逐轮定位耗时与产物
D4
后台管理
任务列表（Success / Needs review / Failed）+ Round 0–3 轮次卡（过程图、耗时）+ Prompt 模板在线编辑
!关键源码事实
1API Key 仅存服务端环境变量，浏览器请求不带 Key
2R0 分析只传基础图，商品图参考发生在 R1/R2 与 QC
3重新生成 = 新建任务从 R0 重来，不是自动重试
4任务状态由浏览器 localStorage 保存，无服务端数据库
◆核心价值
一张房间照片 + 一张商品图 + 一句话
→ 经视觉质检的融合效果图
№关键指标（实测）
41–45 秒单轮生图实测耗时（不含排队）
150 次单轮轮询上限，超过按超时处理
约 12 段本地历史对话保存上限
R0–R3每任务记录四轮过程图、耗时与 request_id
